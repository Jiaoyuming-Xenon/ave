# 01 · 项目概述与交付标准

[返回总览](../demo.md) · [架构](02-architecture.md) · [验收路线](08-delivery.md)

## 1. 产品定位

这是一个**本地优先、Agent 驱动、可视化监督的视频编辑工作台**，不是聊天框套壳、通用非编软件或一次性视频生成脚本。

目标用户是希望在桌面处理本地素材、用自然语言加速重复编辑，同时需要人工控制生成区域、成本、质量和最终交付的创作者。手机是同一桌面工作区的远程监督端，不是独立云端项目，也不承担复杂帧修。

### 核心使用闭环

1. 桌面导入本地视频，生成不可变 Asset、媒体报告、代理和候选镜头。
2. 用户以自然语言描述目标；Agent 先读取必要镜头/帧/音频信息，再提交 EditPlan。
3. 用户修改、拒绝或批准计划；确定性操作进入时间线，局部语义创作先确认 mask 和锚帧。
4. JobRunner 执行预览任务，桌面/Android 展示真实阶段、产物、错误和成本。
5. 用户对比原片/结果，修正 mask/锚点/参数或重新生成单个片段。
6. 最终渲染经过全片 QA 和人工批准后导出视频及 ExportManifest；Android 可下载该交付。

## 2. 用户角色与权限

| 角色 | 典型操作 | 明确限制 |
| --- | --- | --- |
| 桌面项目所有者 | 导入、编辑、修 mask、批准、导出、配置 Worker | 不允许覆盖原始资产；高风险上传需确认 |
| 远程 viewer | 查看会话、计划、进度、代理和 QA | 无上传、写指令、取消、审批或导出权限 |
| 远程 operator | viewer + 上传、追加指令、取消、批准、下载 | 不能改后端/凭据/配对；过期 revision 必须重审 |
| Worker | 执行声明过能力的受控任务 | 无项目审批、数据库状态迁移或任意宿主文件权限 |
| Agent | inspect、propose、提交已批准执行请求 | 无审批权、通用 shell、任意路径和完成状态伪造权 |

MVP 是单用户、单桌面 daemon、若干受信设备；不承诺多租户协作和不可信设备接入。

## 3. 功能范围

### 3.1 P0：发布必须具备

| 编号 | 能力 | 可验收结果 |
| --- | --- | --- |
| F-01 | 本地导入与资产保护 | SHA-256、流/PTS/色彩报告、代理可播放；源 hash 前后不变 |
| F-02 | 镜头与帧检查 | 候选镜头可拆分/合并，接触表时间码可回溯到源帧 |
| F-03 | Agent 计划 | 结构化 EditPlan 含范围、操作、依赖、成本、风险和验收；可修改/拒绝/批准 |
| F-04 | 确定性编辑 | trim、concat、gap、crop、scale、rotate、静音、gain、基础字幕策略 |
| F-05 | 真实局部生成 | 点选/框选 → SAM2 mask → 锚帧/参考图 → VACE 短镜头 → 合成 → QA |
| F-06 | 交互审查 | 原/结果切换与并排、帧步进、mask/锚点叠加、计划 diff、失败原因 |
| F-07 | 持久任务 | daemon/UI 重启恢复；取消、失败、重试和重复消息不破坏状态 |
| F-08 | 非破坏历史 | Revision 可回退；旧任务、审批和 QA 不错挂到新 Revision |
| F-09 | 视频导出 | H.264/AAC MP4 profile 或显式无音轨；全片解码、时间线/音画 QA、manifest |
| F-10 | Android 远程 | 配对、会话、进度、预览、审批、取消、上传/下载、重连 |
| F-11 | 三桌面平台 | Windows/macOS/Linux 安装、启动、真实编辑、导出和远程联调 |

### 3.2 P1：有证据后再启用

- OTIO 交换导出、更多生成/补全后端、远程 GPU Worker 池。
- 更复杂的变速、转场、调色、音频混音和字幕烧录。
- HDR 确定性剪辑专项支持、macOS/Windows 原生生成 Worker。
- 自动质量指标的硬门；必须先经人工标注集标定。

### 3.3 明确不承诺

- iOS、鸿蒙、多用户团队协作、云端素材市场。
- 任意长片/分辨率/复杂编辑一次成功、电影级一致性、专业调色或完整 NLE 替代。
- 任意稀疏关键帧严格满足、单帧可靠传播到所有镜头、无人工 mask 修正。
- 无兼容 GPU 也可生成、模型全部免费/离线/可商用、跨 GPU 同 seed 位级一致。
- VACE 输出天然保留源音频、字幕、VFR、HDR、附件或原始时间戳。
- 精确口型、音乐/配音生成、多机位同步；这些需要独立后端和验收。

## 4. 非功能需求

| 类别 | 要求 | 验证方式 |
| --- | --- | --- |
| 本地与隐私 | 默认素材不离开桌面；云端/远程 Worker 前列出上传镜头、图片、音频和 prompt | 网络审计、审批记录、日志脱敏检查 |
| 数据安全 | 源只读；CAS 临时写入 + hash + 原子 rename；Revision pin 防止 GC 误删 | 故障注入、源 hash、恢复与 GC 测试 |
| 可靠性 | Job 与 UI 进程解耦；lease fencing、幂等完成、显式 interrupted/retryable_failed | 杀 Worker、重启 daemon、重复/过期完成 |
| 安全 | 每 RPC 服务端鉴权；无通用 shell；argv 不经 shell；模型字符串不成为路径/命令 | 越权、路径穿越、提示注入、参数注入测试 |
| 性能 | 按设备×模型×分辨率×帧数×steps 记录冷/热 p50/p95、RAM/VRAM/磁盘 | 固定 benchmark；不写无依据固定耗时 |
| 资源 | 默认每 GPU 一个生成 Worker；磁盘/内存准入，队列背压和有限重试 | OOM、磁盘不足、取消和排队测试 |
| 可访问性 | 状态不只靠颜色；键盘操作、焦点、错误文本、图表有文本说明 | 桌面/Android 实际 UI 检查 |
| 可维护性 | 单一 contracts、上游版本锁、ADR、schema migration、依赖和模型 SBOM | contract test、升级/回滚演练、许可审计 |

容量基线不是云端 QPS：首版以单项目、单 daemon、单活动 GPU 生成任务为调度单位。瓶颈指标是任务排队时间、每阶段时延、峰值 RAM/VRAM 和磁盘，而不是虚构 DAU。

## 5. 平台交付标准

| 平台 | 交付物 | 完整职责 | 验收证据 |
| --- | --- | --- | --- |
| Windows x64 | 签名 NSIS `.exe` | 编辑、预览、导出；CUDA/WSL Worker 仅按实测支持 | 干净 Windows 机器安装、源保护、导出、升级卸载 |
| macOS x64/arm64 | 签名并公证 `.dmg` | 编辑、预览、导出；VACE 原生能力不预先承诺 | 每种发布的架构均须真实系统验收；未实测架构不发布 |
| Linux x64 | `.AppImage` | 编辑、预览、导出；本地/远程 Worker 按能力探测 | 干净发行版运行、FFmpeg/驱动回退、远程联调 |
| Android | `.apk` | 远程会话、预览、审批、取消、上传/下载 | 真机杀进程、后台、网络切换、权限和重连 |

Web UI 成功、Linux 开发机成功或 Expo snack 成功均不能替代目标安装包/真机验收。

## 6. 完成定义（Definition of Done）

一个能力只有同时满足以下条件才可标记完成：

1. **行为**：正常、失败、取消和恢复路径均实现，不只走 happy path。
2. **契约**：schema、权限、幂等、兼容和错误码有测试；没有第二份私有 DTO。
3. **媒体真实性**：使用真实素材和可播放输出；源 hash 不变，产物与 Revision 绑定。
4. **质量门**：确定性检查通过；生成内容还需人工审阅，未标定 AI 指标不能自动放行。
5. **平台证据**：对应安装包或真机已验证；未运行平台明确标为未验证。
6. **可追溯**：记录代码、依赖、FFmpeg 构建、模型/权重、seed、mask 和 QA 版本。
7. **文档与状态**：使用说明、限制、`research/team.json` 证据和验证记录同步更新。

提交数、有效代码行、文档页数、模型文字评语和打字动画都不是完成证据。
